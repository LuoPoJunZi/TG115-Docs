# Bot 命令

Bot 只接受配置用户在一对一私聊中发送的命令。

| 命令 | 用途 |
| --- | --- |
| `/start`、`/help` | 查看使用帮助 |
| `/queue [页码]` | 每页查看 5 个最近任务，默认第 1 页 |
| `/status`、`/performance` | 查看同一份系统状态、性能和任务统计 |
| `/doctor` | 只读诊断，不创建远端测试文件 |
| `/task <编号>` | 查看单个任务详情 |
| `/watch <编号>` | 每 5 秒更新一次任务进度；Bot 重启后需重新订阅 |
| `/pause`、`/resume` | 持久暂停或恢复新任务调度，不中断正在传输的任务 |
| `/retry <编号>` | 重试一个可重试任务 |
| `/retry all` | 一次重新排队最多 100 个可重试任务 |
| `/cancel <编号>` | 取消任务，并按安全顺序清理其远端临时文件和本地副本 |
| `/stream <编号>` | 将排队或下载失败任务切换为流式模式 |
| `/orphans` | 只读巡检未被活动任务跟踪的 `.uploading-*` 临时文件 |
| `/orphans clean` | 获取一次性确认码，再显式执行遗留文件清理 |

## Telegram 原生命令菜单

Bot 启动时会尝试注册 7 个常用入口：

```text
/status   查看系统状态
/queue    查看最近任务
/pause    暂停任务调度
/resume   恢复任务调度
/doctor   运行系统诊断
/orphans  检查临时文件
/help     查看使用帮助
```

菜单注册失败不会阻止 Bot 启动，仍可手动输入全部命令。

::: warning 谨慎使用清理命令
`/orphans` 本身只读。发送 `/orphans clean` 后，Bot 会给出有效期 5 分钟的一次性确认码；只有携带该确认码再次发送命令才会清理，并会在清理前重新扫描、删除后复查。
:::

::: info 旧版 `/confirm`
`/confirm <编号|all>` 仅为兼容旧版本工作流而保留，当前日常使用不需要逐任务确认。它只修改 Bot 的历史记录，不会触发上传，也不能证明 115 官方端已经完成入库。
:::
