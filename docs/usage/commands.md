# Bot 命令

TG115 当前文档中的常用命令包括：

| 命令 | 用途 |
| --- | --- |
| `/start` | 初始化或查看入口提示 |
| `/help` | 查看帮助 |
| `/queue` | 查看队列 |
| `/status` | 查看服务与当前传输状态 |
| `/performance` | 查看性能相关信息 |
| `/task <任务编号>` | 查看指定任务 |
| `/confirm <任务编号>` | 记录 115 官方端人工确认 |
| `/retry <任务编号>` | 重试任务 |
| `/cancel <任务编号>` | 取消任务 |

::: warning `/confirm` 的含义
`/confirm` 只记录用户已经在 115 官方客户端完成检查，不会再次上传文件，也不会自动修改 115 中的文件。
:::
