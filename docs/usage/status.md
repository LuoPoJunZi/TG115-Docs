# 任务状态

理解状态是排错的第一步。Bot 可能根据任务模式和执行阶段显示下列状态。

| 状态 | 含义 |
| --- | --- |
| 在排队 | 任务已持久化，正在等待资源、磁盘空间或目的端放行 |
| 已放行，准备下载 | 调度器已为任务预留资源，即将开始普通下载或流式传输 |
| 正在从 Telegram 下载 | 普通模式正在把文件写入 VPS 临时目录 |
| 正在从 Telegram 流式写入 CloudDrive2 | 文件直接进入上传管道；此处进度不是 115 官方端入库进度 |
| 下载完成，等待上传 | Telegram 下载已完成，正在等待共享上传窗口 |
| 正在写入 CloudDrive2 | 本地完整文件正在通过 WebDAV 上传 |
| 正在校验 CloudDrive2 文件 | Bot 正在复验远端文件大小 |
| 正在生成正式文件名 | Bot 正在把临时文件安全改名为最终文件名 |
| CloudDrive2 已接收，正在清理 VPS 本地文件 | 远端已复验，本地清理尚未完成 |
| Bot 传输已完成（CloudDrive2 已接收） | Bot 流程结束；仍应在 115 官方客户端核验 |
| 下载失败 | Telegram 下载或流式传输失败，可排查后重试 |
| 上传失败，本地文件已保留 | WebDAV 上传失败，本地完整文件保留用于重试 |
| 校验失败，本地文件已保留 | 远端复验失败，本地完整文件保留用于重试 |
| 已取消 | 用户取消了任务，Bot 已停止继续调度该任务 |

状态展示会根据上下文使用更具体的文案，但判断原则不变：`Bot 传输已完成` 只表示 CloudDrive2 WebDAV 链路已完成并复验，不等同于 115 官方端最终入库完成。

::: info 历史状态兼容
旧数据库中的 `confirmed` 状态会统一显示并计入“Bot 完成”。兼容命令 `/confirm` 不再是当前工作流的必需步骤。
:::
