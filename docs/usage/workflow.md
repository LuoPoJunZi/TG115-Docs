# 文件转存流程

## 普通文件

```text
Telegram
  ↓
下载到 VPS 临时目录
  ↓
rclone 上传
  ↓
CloudDrive2 WebDAV
  ↓
远端校验
  ↓
清理 VPS 本地文件
```

普通模式的优势是：上传失败时可以保留本地完整文件，便于后续重试。

## 大文件流式模式

当单文件超过本地任务预算时，TG115 可以改用流式路径：

```text
Telegram → rclone → CloudDrive2
```

这样不会先把整个文件完整写入 VPS，但网络中断后通常需要从头重新传输。

## 最终确认

TG115 会把“Bot 已完成 WebDAV 侧传输”与“用户已在 115 官方客户端确认”区分开。

确认文件在 115 官方客户端中大小正常且可打开后，再使用 `/confirm <任务编号>` 记录人工确认。
