# 文件转存流程

## 普通文件

```text
Telegram
  ↓
下载到 VPS 临时目录
  ↓
rclone 上传
  ↓
CloudDrive2 WebDAV
  ↓
远端校验
  ↓
清理 VPS 本地文件
```

普通模式的优势是：上传失败时可以保留本地完整文件，便于后续重试。

## 大文件流式模式

当单文件超过本地任务预算时，TG115 可以改用流式路径：

```text
Telegram → rclone → CloudDrive2
```

这样不会先把整个文件完整写入 VPS，但网络中断后通常需要从头重新传输。

## 完成语义与官方端核验

Bot 显示“Bot 传输已完成（CloudDrive2 已接收）”时，表示 TG115 已完成 WebDAV 写入、远端复验和主要清理流程。CloudDrive2 后续如何同步到 115 不由 TG115 控制。

因此，重要文件仍应在 115 官方客户端检查文件是否出现、大小是否正确并能正常打开。当前流程无需逐任务发送 `/confirm`；该命令仅为旧版记录方式保留。
