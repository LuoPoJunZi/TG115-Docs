# FAQ：部署与连接

## VPS 没有 `/dev/fuse`

CloudDrive2 官方 Docker 挂载方式依赖 FUSE。请：

1. 在 VPS 中检查 `/dev/fuse` 是否存在；
2. 查看服务商控制台是否有“FUSE / TUN / 容器权限”开关；
3. 如果是容器型 VPS，联系服务商确认宿主机是否允许 FUSE。

如果服务商完全不支持 `/dev/fuse`，当前推荐部署方式无法正常使用 CloudDrive2 挂载。

## SSH 连接失败

依次检查：

- VPS IP / 域名；
- SSH 端口；
- 用户名；
- 密码或私钥；
- 服务商安全组；
- VPS 防火墙；
- 非 root 用户是否具备 sudo 权限。

## 首次 SSH 指纹应该怎么确认

部署器第一次连接会显示服务器主机密钥指纹。应与 VPS 服务商控制台、初始化邮件或你通过可信渠道取得的指纹核对。不要在无法确认服务器身份时直接接受未知指纹。

## Windows 提示“未知发布者”或安全软件报警

TG115 部署器使用 PyInstaller 生成单文件 EXE，未签商业代码签名证书时，部分 Windows 安全机制会给出启发式提示。

处理原则：

1. 只从正式 GitHub Releases 下载；
2. 校验 `SHA256SUMS.txt`；
3. 如有疑问，查看随 Release 提供的源代码并自行构建。

## 日志出现 `lookup clouddrive2`

说明 Bot 到 CloudDrive2 的 Docker 网络解析/别名可能异常。

优先使用部署器中的：

```text
修复 CloudDrive2 网络
```

修复后重新执行真实 WebDAV 验收。

## 为什么不能直接打开 VPS:19798

部署器管理的 CloudDrive2 端口应只绑定 VPS 本地回环地址，通过 SSH 隧道访问管理页。这样不需要把管理端口直接暴露公网。

使用部署器的：

```text
打开 CloudDrive2 管理页
```

它会建立隧道并打开类似：

```text
http://127.0.0.1:随机端口
```

## 修改配置后为什么验收还是旧配置

如果你只修改部署器输入框后直接点“WebDAV 验收”，VPS 上的正式配置并不会自动更新。

正确顺序：

1. 修改部署器参数；
2. 重新执行“一键部署基础环境”；
3. 等待部署成功；
4. 再执行 WebDAV 验收。
