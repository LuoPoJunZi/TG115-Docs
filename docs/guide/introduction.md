# 项目介绍

TG115 是一个个人自托管文件转存工具。典型场景是：在 Telegram 中找到需要保存的文件，将它转发给自己的私人 Bot，VPS 自动完成后续处理，并通过 CloudDrive2 WebDAV 写入已挂载的 115 网盘。

## 工作链路

```text
Telegram 文件
    ↓
私人 Telegram Bot
    ↓
TG115 任务队列
    ↓
VPS 下载 / 流式读取
    ↓
rclone
    ↓
CloudDrive2 WebDAV
    ↓
115 网盘
```

## 主要能力

- Windows 图形化一键部署器；
- 私聊 Bot 接收文件；
- SQLite 持久化任务队列；
- CPU、内存、磁盘、网络等资源状态参与调度；
- 普通落盘与大文件流式两种传输路径；
- WebDAV 写入后的大小校验与远端改名；
- 仅允许指定 Telegram 数字 ID 使用；
- 将“Bot 传输完成”和“115 官方端确认”分开记录。

## 适用范围

当前文档以个人、一对一私聊、自建 VPS 的使用方式为主。不建议把它当作多人共享文件服务或公网文件分发服务。
