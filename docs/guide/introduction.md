# 项目介绍

TG115 是一个个人自托管文件转存工具。典型场景是：在 Telegram 中找到需要保存的文件，将它转发给自己的私人 Bot，VPS 自动完成后续处理，并通过 CloudDrive2 WebDAV 写入已挂载的 115 网盘。

本项目是在原作者 [whyhhh20/TG115](https://github.com/whyhhh20/TG115) 基础上的二次开发版本，v1.6.x 重点加强了任务恢复、磁盘保护、流式传输、部署回退、资源建议和日常诊断。项目继续使用 MIT 许可证。

## 工作链路

```text
Telegram 文件
    ↓
私人 Telegram Bot
    ↓
TG115 任务队列
    ↓
VPS 下载 / 流式读取
    ↓
rclone
    ↓
CloudDrive2 WebDAV
    ↓
115 网盘
```

## 主要能力

- Windows 图形化一键部署器；
- 私聊 Bot 接收文件；
- SQLite 持久化任务队列；
- CPU、内存、磁盘、网络等资源状态参与调度；
- 普通落盘与大文件流式两种传输路径；
- WebDAV 写入后的大小校验与远端改名；
- 仅允许指定 Telegram 数字 ID 使用；
- 将“CloudDrive2 已接收”和“115 官方端实际可用”明确区分。

## 适用范围

当前正式支持配置用户与 Bot 的一对一私聊。群组和频道消息不会创建任务；当前版本也不自动监听频道或批量抓取频道历史。

请只转存你有权保存、备份和使用的内容，并遵守 Telegram、115、CloudDrive2、内容来源平台及所在地的法律法规和服务条款。不建议把 TG115 当作多人共享文件服务或公网文件分发服务。
